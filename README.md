# 📧 Spring Boot Email Sender

A simple Spring Boot application that allows you to send emails with a web-based UI.  
Users can enter recipient email, subject, and message, and send emails directly.  

---

## 🚀 Features
- Send email using Gmail SMTP.
- User-friendly UI built with Thymeleaf.
- Enter **Recipient Email**, **Subject**, and **Message**.
- Sends mail instantly.

---

## 🛠 Tech Stack
- **Java 17+**
- **Spring Boot**
- **Spring Mail (JavaMailSender)**
- **Thymeleaf**
- **Maven**
